Live Product

MILLEON

The daily stock rarity game. Every day brings 7 prompts about the S&P 500 — any correct stock scores, rarer answers score more, and one answer in every prompt is the jackpot. No account needed; just you and a 25-second clock.

  • The stock everyone names scores 10. Rarer picks score 30, 55, or 80 by rarity, and the jackpot answer in each prompt scores 100 — 700 is a perfect game.
  • A nightly refresh rebuilds the next day's set: every prompt is validated at 15–150 correct answers against fresh S&P 500 data, and scores are locked server-side when a player finishes.

STACKED

A dividend and portfolio tracker for investors who'd rather check an app than a spreadsheet. STACKED brings holdings, dividend income, and live market data together in one React Native app.

  • Built with React Native, TypeScript, and Supabase, with Row Level Security to keep user portfolio data isolated and secure.
  • Market data is pulled from Yahoo Finance, and OpenAI-powered insights are layered on top to explain portfolio movements.

Security + Integrity

Document Verification Platform

Built for academic credential verification, where a document is only useful if its authenticity can be proven. The platform hashes uploaded files, records proofs on-chain, and gives users a simple workflow to confirm whether a document has been altered.

  • Connected a Django application to a Ganache-based blockchain environment through Web3.py so uploads and verification could happen through a normal web interface.
  • Used SHA-256 hashing and re-upload verification to compare stored blockchain records against submitted files and flag authentic versus inauthentic documents.
